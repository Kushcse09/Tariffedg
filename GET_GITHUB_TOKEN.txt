═══════════════════════════════════════════════════════════════
  HOW TO GET YOUR GITHUB PERSONAL ACCESS TOKEN
═══════════════════════════════════════════════════════════════

WHAT IS IT?
A token is like a temporary password that lets you push code to GitHub.

It looks like this:
ghp_1a2b3c4d5e6f7g8h9i0j1k2l3m4n5o6p7q8r
    ↑
    Starts with "ghp_"

───────────────────────────────────────────────────────────────
STEP-BY-STEP INSTRUCTIONS
───────────────────────────────────────────────────────────────

1. GO TO TOKEN PAGE
   
   Click this link:
   https://github.com/settings/tokens
   
   (Make sure you're logged in as Kushcse09)

───────────────────────────────────────────────────────────────

2. CLICK "Generate new token"
   
   You'll see two options:
   - Generate new token (classic)  ← Click this one
   - Generate new token (beta)

───────────────────────────────────────────────────────────────

3. FILL IN THE FORM
   
   Note (name):
   ┌──────────────────────────────┐
   │ TariffEdge Push              │
   └──────────────────────────────┘
   
   Expiration:
   ┌──────────────────────────────┐
   │ 7 days             [▼]       │
   └──────────────────────────────┘
   
   Select scopes:
   ☑ repo  ← CHECK THIS BOX (it will check all sub-boxes)
   ☐ workflow
   ☐ write:packages
   ☐ delete:packages
   
   (Only check "repo", leave others unchecked)

───────────────────────────────────────────────────────────────

4. CLICK "Generate token" (green button at bottom)

───────────────────────────────────────────────────────────────

5. COPY YOUR TOKEN!
   
   You'll see a green box with your token:
   
   ┌────────────────────────────────────────────┐
   │ Personal access tokens (classic)           │
   ├────────────────────────────────────────────┤
   │ Make sure to copy your personal access     │
   │ token now. You won't be able to see it    │
   │ again!                                     │
   │                                            │
   │ ghp_aBc123XyZ789...                [Copy] │
   └────────────────────────────────────────────┘
   
   ⚠️  IMPORTANT: Click the [Copy] button!
   ⚠️  You can ONLY see this ONCE!
   ⚠️  Paste it in Notepad temporarily!

───────────────────────────────────────────────────────────────
AFTER YOU COPY THE TOKEN
───────────────────────────────────────────────────────────────

Open PowerShell and run these commands:

1. Navigate to project:
   cd c:\Users\kusha\Downloads\tariffedge-main

2. Update remote with your token:
   git remote set-url origin https://YOUR_TOKEN@github.com/Kushcse09/Tariffedg.git
   
   ↑ Replace YOUR_TOKEN with the token you copied

3. Push to GitHub:
   git push -u origin master --force

───────────────────────────────────────────────────────────────
EXAMPLE
───────────────────────────────────────────────────────────────

If your copied token is:
ghp_abc123xyz789def456ghi012jkl345mno678pqr

Then the command would be:
git remote set-url origin https://ghp_abc123xyz789def456ghi012jkl345mno678pqr@github.com/Kushcse09/Tariffedg.git

Then push:
git push -u origin master --force

───────────────────────────────────────────────────────────────
VERIFY SUCCESS
───────────────────────────────────────────────────────────────

After pushing, visit:
https://github.com/Kushcse09/Tariffedg

You should see all your project files!

───────────────────────────────────────────────────────────────
TROUBLESHOOTING
───────────────────────────────────────────────────────────────

Error: "repository not found"
→ Create the repository first at https://github.com/new

Error: "permission denied"
→ Check that you copied the token correctly
→ Make sure the token has "repo" scope checked

Error: "token expired"
→ Generate a new token (they expire after 7 days)

═══════════════════════════════════════════════════════════════

SECURITY TIP:
After pushing, remove the token from the URL:

git remote set-url origin https://github.com/Kushcse09/Tariffedg.git

This keeps your token private!
