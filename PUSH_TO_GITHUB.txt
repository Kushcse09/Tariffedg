───────────────────────────────────────────────────────────────
METHOD 1: GitHub CLI (Recommended if installed)
───────────────────────────────────────────────────────────────

1. Install GitHub CLI (if not installed):
   Download from: https://cli.github.com/

2. Authenticate:
   gh auth login
   
   Choose:
   - GitHub.com
   - HTTPS
   - Login with a web browser
   - Follow the browser prompts

3. Push:
   git push -u origin master

───────────────────────────────────────────────────────────────
METHOD 2: Personal Access Token (PAT)
───────────────────────────────────────────────────────────────

1. Create PAT:
   a. Go to: https://github.com/settings/tokens
   b. Click "Generate new token" → "Generate new token (classic)"
   c. Give it a name: "TariffEdge Hackathon"
   d. Select scopes: ☑ repo (all sub-scopes)
   e. Click "Generate token"
   f. COPY THE TOKEN (you won't see it again!)

2. Update remote with token:
   git remote set-url origin https://YOUR_TOKEN@github.com/Kushcse09/Tariffed.git
   
   Replace YOUR_TOKEN with the token you copied

3. Push:
   git push -u origin master

───────────────────────────────────────────────────────────────
METHOD 3: Manual Push via Browser
───────────────────────────────────────────────────────────────

1. Create repository on GitHub:

   - DON'T initialize with README
   - Create repository

2. GitHub will show push commands - use those

3. When prompted for password, use Personal Access Token (create as above)
